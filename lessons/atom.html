Теория

Ядро и спектр

Z — число протонов, A = Z + N — число нуклонов. Изотопы различаются N. Протон и нейтрон — составные частицы, их валентный кварковый состав uud и udd. Энергия связи ядра равна [Zmₚ + Nmₙ − m(ядра)]c². Резерфорд установил наличие компактного ядра, Бор связал дискретный спектр с переходами между стационарными состояниями.

Вывод формулы Бора

Для одноэлектронной частицы при круговой орбите кулоновская сила даёт mv² = Ze²/(4πε₀r), а условие Бора mvr = nℏ даёт rₙ ≈ a₀n²/Z. Полная энергия равна половине кулоновской потенциальной, поэтому Eₙ ≈ −13,6Z²/n² эВ без поправки на приведённую массу. При переходе hν = |ΔE|. Для многоэлектронных атомов вводят электронное взаимодействие.

Волновая функция и плотность

ψ — амплитуда вероятности, |ψ|² — плотность вероятности. Для нормированной угловой части радиальная вероятность равна r²|Rₙₗ(r)|²dr. У 1s плотность максимальна в ядре, тогда как радиальная вероятность максимальна при r = a₀. 2s имеет один радиальный узел, 3s два, 2p и 3d имеют ноль. p-орбитали имеют один угловой узел, d — два. Δx·Δpₓ ≥ ℏ/2 ограничивает одновременную определённость координаты и импульса.

Подуровни и заполнение

s, p, d, f соответствуют ℓ = 0, 1, 2, 3. Число орбиталей 2ℓ+1, с учётом принципа Паули емкость 2(2ℓ+1). Сумма от ℓ = 0 до n−1 даёт 2n². По Хунду в вырожденных орбиталях сначала заполняют разные орбитали с параллельными спинами. Правило n+ℓ приближённо. Cr имеет [Ar]3d⁵4s¹, Cu — [Ar]3d¹⁰4s¹. В катионах 4s обычно опустошается раньше 3d. Типичная конфигурация лантаноида [Xe]4fⁿ5d⁰⁻¹6s². У актиноидов заполняются 5f и близкие 6d.

★ Экранирование

В модели Слэтера Zэфф = Z − S. Для ns/np другие электроны той же группы дают по 0,35 (в 1s 0,30), электроны слоя n−1 по 0,85, более глубокие по 1. Для nd/nf электроны всех предшествующих групп дают по 1, другие той же группы по 0,35. Правила приближённы и дают орбитально-зависимое экранирование.

★ Как выбирать радиальную диаграмму

У водородоподобного атома для 1s R(r) пропорциональна exp(−Zr/a₀), так что P(r) пропорциональна r²exp(−2Zr/a₀). Логарифмическая производная 2/r−2Z/a₀ обращается в ноль при r=a₀/Z. Для 2s у радиального множителя есть нуль r=2a₀/Z, тогда как у 2p в положительной области узлов нет. В 3p один радиальный узел, в 3d ни одного. У реального многоэлектронного атома рисунок отражает тот же счёт узлов для соответствующей центральнополевой модели, а положение экстремумов меняется.

Аналогия · Вероятность попадания

Вероятность в тонкой сферической оболочке зависит и от плотности, и от площади оболочки. В центре площадь исчезает, даже если локальная плотность высока.
